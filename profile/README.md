### 📌 About Some(CS)

**Some(CS)** is an independent software studio and open-source organization focused on building high-performance systems, containerized developer environments, and accessible computer science tooling. 

We bridge the gap between low-level performance and modern developer workflows, delivering production-grade architectures and modular open-source software.

---

### 🎯 Core Focus Areas

* **Systems & Backend Engineering:** Building memory-safe, concurrent backends, gRPC services, and microservice architectures primarily in Rust.
* **Developer Tooling & Cloud Workspaces:** Maintaining ready-to-code Dev Container templates, Codespace configurations, and standard boilerplates.
* **Full-Stack Application Design:** Crafting type-safe, resilient web and mobile applications with scalable system design.
* **Practical CS Education:** Creating clear, practical educational modules, algorithmic breakdowns, and structured technical blueprints.

---

### 🛠️ Technology Stack & Tooling

* **Systems & Languages:** Rust, TypeScript, JavaScript, SQL
* **Architecture & Backend:** Actix-web, Tonic (gRPC), Node.js, Redis, MongoDB
* **Frontend & Mobile:** Next.js, React, React Native, Tailwind CSS
* **Environment & CI/CD:** Docker, GitHub Codespaces, Dev Containers, GitHub Actions
